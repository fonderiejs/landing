What is Fonderie?

Fonderie is an open-source skill and TypeScript SDK that lets AI coding assistants build SaaS products from pre-made, production-tested modules — login, billing, teams, and permissions — instead of regenerating that code from scratch each session. It runs on your own server, and the source is on GitHub.

Which AI coding assistants work with Fonderie?

Fonderie works with Claude Code natively, with Cursor via rules, and with Codex via AGENTS.md. Because the skill is plain instructions plus a TypeScript SDK, any model that can read a repository can use it. Install once with npm install @fonderie/core.

How is this different from a BaaS like Supabase or Clerk?

Those are hosted services you rent and configure through dashboards and SDKs. Fonderie is source code your AI composes directly — self-hosted, auditable, and designed for agentic workflows rather than human dashboard-clicking. It orchestrates external services like Stripe or Slack where you want them, but the core runs on your own infrastructure with no vendor lock-in.

Is Fonderie open source?

Yes. Fonderie Core is seventeen open-source building blocks — auth, billing, workspaces, permissions, and more — written in plain TypeScript and self-hosted on your own infrastructure, with no vendor lock-in. You can read, audit, and modify every module at github.com/fonderie-js/sdk.
